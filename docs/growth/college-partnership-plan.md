# College partnership plan

Explicitly not a repeat of the prior 68-college generic blast (`docs/salaryexit-distribution-forensics.md` §7.1). This plan targets 10-15 institutions with **active, real, currently-live** placement/career resources — verified via web search this session where noted — and offers a specific, useful asset instead of a soft "please share this" ask.

## The asset: First Offer Reality Guide for Indian Graduates

A downloadable PDF (to be produced from existing site content — not yet built as a standalone PDF in this pass) covering:
- CTC vs. gross vs. in-hand, with a worked example
- Variable pay: what's guaranteed vs. contingent
- Employer PF: what it means for take-home vs. retirement
- Gratuity: the 5-year vesting reality
- Monthly in-hand: how to estimate it before the first payslip
- Offer-comparison checklist (same content as the LinkedIn Week 3 carousel)
- QR/link to the calculators and the flagship report

**Not yet built in this pass:** the actual PDF file. This plan specifies its content; producing the polished PDF is a Week 1-2 execution task, not something fabricated here as if it already existed.

## Offer, in order of ask size

1. **Downloadable PDF inclusion** on the placement-cell resource page — lowest-friction ask, most likely to convert.
2. **Newsletter excerpt** — if the institution runs a placement-cell or alumni newsletter, offer a short excerpt version.
3. **Free embed** of the in-hand salary table on their resource page.
4. **Campus webinar** (20-30 minutes) — highest-effort ask, offered only after a positive reply to one of the above, not as the opening pitch.

## What this explicitly avoids repeating

- No single generic email to a large batch — max 10-15 targeted institutions this quarter, personalized per institution's actual current resource page.
- No guessed or truncated email addresses — the prior campaign's own practice (declining to guess 15 truncated Airtable addresses) is the standard to keep, not lower.
- No re-sending the identical prior template to the 3 follow-up institutions — see `outreach-templates.md`'s "already contacted once" variant.
