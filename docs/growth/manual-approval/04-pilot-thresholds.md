# Pilot thresholds — approval summary

Full table: `docs/growth/growth-dashboard-spec.md` → "Baseline-relative pilot thresholds." Condensed here.

| Metric | Weekly baseline | Continue/scale | Stop/reassess |
|---|---|---|---|
| Sessions (site-wide) | ~9.2/week | ≥14/week, 2 weeks straight | <7/week, 2 weeks straight, no engagement gain |
| Engaged sessions | ~7.1/week | ≥11/week, 2 weeks straight | <5/week, 2 weeks straight |
| `calculator_use` events | ~5.1/week | ≥8/week, 2 weeks straight | <3/week, 2 weeks straight |
| LinkedIn engaged sessions/post | ~0.7/week baseline | ≥2 per post | 0 across 2 consecutive same-format posts |
| Reddit engaged sessions/post (72h) | bursty — real cluster was 13 in 4 days | ≥4 within 72h | 0 within 72h |
| GSC clicks | ~3.9/week | Trending up 3+ weeks straight | Declining 3+ weeks straight |

**These numbers are intentionally low.** They reflect where the site's real traffic is today, not an aspirational target. A pilot post that gets 2 LinkedIn engagements or a week with 11 engaged sessions is a real, above-baseline result at this stage — not a disappointing one. Approving the pilot means accepting these as the honest bar, not a placeholder that will later look too easy.

**Decision cadence**: weekly, every Friday, per `growth-dashboard-spec.md`'s existing review format — this package does not change the cadence, only the numbers behind each decision.
